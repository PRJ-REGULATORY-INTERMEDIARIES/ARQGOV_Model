# ARQGOV Model — Interactive Governance Atlas

## [👉 Clique aqui para ver o modelo interativo](https://prj-regulatory-intermediaries.github.io/ARQGOV_Model/)

**Endereço do GitHub Pages:** https://prj-regulatory-intermediaries.github.io/ARQGOV_Model/

> A URL acima estará operacional assim que o GitHub Pages estiver habilitado em **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**.

Atlas visual e interativo inspirado no manuscrito preliminar de David Levi-Faur, *Law and the Architectures of Governance: Towards Relational Leximetrics Approach*.

### Exploração
- Mapa das oito dimensões: objetos, atores, funções, mecanismos, relações, estratégias, arquiteturas e lógicas de governança.
- Catálogo pesquisável de 83 categorias com indicação das seções do manuscrito.
- Exemplo didático de sete vínculos entre regulador, intermediário, firma e consumidor.
- Metodologia de observação relacional, atributos, indicadores e pontos de auditoria.

**Estatuto científico:** reconstrução visual interpretativa para discussão acadêmica; não constitui endosso formal do autor. O manuscrito é preliminar e há categorias ainda incompletamente operacionalizadas.

**Privacidade:** repositório público; confirme com o autor a autorização para divulgar definições do manuscrito.
