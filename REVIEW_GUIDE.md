# ARQGOV — Conceptual Review Guide

**Research manuscript:** *Law and the Architectures of Governance: Towards Relational Leximetrics Approach* (David Levi-Faur; preliminary version).

## What to review

The original atlas has eight analytical dimensions: Objects, Actors, Functions, Mechanisms, Relationships, Strategies, Architectures, and Governance Logics. Its 83 entries are preserved. Use the review module to comment on a whole dimension, a category, a specific source field, a theoretical-map connection, an illustrative network relation or an additional measurement. Blank or partial manuscript fields remain blank/partial: proposed definitions belong in the review, not in the source inventory.

## How to give feedback

1. Open any category or dimension and select its **Review** button. For more precise feedback, use **Review this field** beneath an individual definition, example or other manuscript field.
2. Add your name. Email is optional. Choose one of five assessment types: Keep as proposed; Clarification needed; Suggest a revision; Potential overlap with another category; Further discussion needed.
3. Add a comment and, optionally, a proposed alternative wording. Click **Save note locally**. You may review several elements independently.
4. Open **Review notes** to edit a saved note, export a structured CSV, or download/restore a JSON backup.
5. To submit: first select **Download CSV for Igor**, then **Prepare email** and attach the downloaded `.csv` file. The email button does not attach or send any file automatically.

## CSV record

Each review item includes:

`schema_version,model_version,manuscript,reviewer_name,reviewer_email,review_item_id,element_type,element_id,dimension_id,category_label,field_label,source_reference,original_text,assessment,comment,proposed_revision,updated_at_utc`

The source text is kept separate from the reviewer comment and proposal. Connection reviews expressly concern an editorial visual interpretation, rather than an author-certified statement. The timestamp comes from the browser device; reviewer identity is self-declared.

## Important limitations

- This is an exploratory review instrument, not a system for automatic acceptance or adjudication of changes.
- Notes are stored in the local browser. Use CSV export and JSON backup before clearing browser data, switching browsers or devices, or using a private/incognito window.
- The website has no receiving backend and makes no automatic transmission to Igor.
- Do not upload any personal review CSV/JSON to a public repository. The published HTML and source inventory themselves remain public if the repository and Pages are public.
